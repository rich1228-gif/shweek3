Sistema de Gestión Hospitalaria

Plataforma desarrollada para administrar pacientes, doctores y citas médicas mediante una aplicación web utilizando HTML, Bootstrap, JavaScript y LocalStorage.

Iniciar Sesión Registrarse

Funcionalidades

Administrador

Gestiona usuarios, asigna roles, administra todas las citas y controla el sistema.

Doctor

Consulta sus citas, registra disponibilidad y marca consultas atendidas.

Paciente

Se registra, solicita citas, consulta su historial y cancela citas.
